# Food Mate Application

Welcome to my portfolio application built with **Next.js**, **React**, **TypeScript**, **Tailwind CSS**, and **Zustand**. This project showcases my skills in web development, project management, and documentation. The application includes user authentication, role-based access control, CRUD operations, and a responsive design.

## Features

- User authentication using **Clerk**
- Connecting **Clerk** user with internal user
- Role-based access control for different user types (admin, user)
- CRUD operations for user management
- Seed Data
  - Basic roles like administrator and simple user
- Responsive design with **Tailwind CSS**
- State management with **Zustand**
- Type-safe code with **TypeScript**

## Technologies Used

- **Next.js**: A React framework for server-side rendering and static site generation.
- **React**: A JavaScript library for building user interfaces.
- **TypeScript**: A superset of JavaScript that adds static types.
- **Tailwind CSS**: A utility-first CSS framework for styling.
- **Zustand**: A small, fast state management solution for React.
- **Clerk**: A user management and authentication service.

## Getting Started

### Prerequisites

- Node.js (version 18 or later)
- npm or yarn

### Installation

1. Clone the repository:

```bash
   git clone https://github.com/yasharvc/FoodMate
   cd FoodMate
```
